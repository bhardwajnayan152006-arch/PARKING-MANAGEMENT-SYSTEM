## Parking Management System

## Introduction

This is a simple Parking Management System made using Python.

It is designed to manage vehicles in a small parking area. The program allows the user to add vehicles, remove vehicles, search for vehicles and check available parking slots.

## Features

- Add vehicle
- Remove vehicle
- Search vehicle
- Show parked vehicles
- Show available parking slots
- Show parking summary
- Count cars and bikes
- Generate parking bill
- Save parking data in a text file
- Save total collection

## Technologies Used

- Python
- Lists
- Functions
- If-else statements
- For loop
- While loop
- Modules
- File handling

## Project Files

- main.py - Main program and menu
- data.py - Stores parking data
- vehicle.py - Vehicle related functions
- validation.py - Checks vehicle type
- parking.py - Vehicle entry and exit
- search.py - Search and parking slot functions
- billing.py - Parking fee and bill
- reports.py - Parking reports
- parking_data.txt - Stores parked vehicle data
- collection.txt - Stores total collection

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

python main.py

4. Select an option from the menu.

## Main Menu

1. Vehicle Entry
2. Vehicle Exit
3. Show Parked Vehicles
4. Search Vehicle
5. Show Available Slots
6. Parking Summary
7. Vehicle Count
8. Exit

## Data Storage

The program uses text files to store data.

parking_data.txt stores the details of parked vehicles.

collection.txt stores the total parking collection.
