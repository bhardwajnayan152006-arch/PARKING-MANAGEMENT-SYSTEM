## Project Statement

## Project Title

Parking Management System

## Problem Statement
Managing vehicles in a parking area manually can be difficult.

This project is made to manage vehicles, parking slots and parking fees using Python.

## Scope

This project can be used in a small parking area like a college or office.

## Target Users

Parking staff and parking managers.

## Main Features

- Add vehicle
- Remove vehicle
- Search vehicle
- Show available slots
- Show parked vehicles
- Calculate parking fee
- Show parking summary

## Objective
The main objective is to make a simple parking management system using Python.
The project uses basic concepts like lists, functions, loops, conditions, modules and file handling.
